Mutation testing for the code your PR changed.

Reapr runs your own Stryker config on the lines your branch changed and shows which changes no test would catch.

Get started View on GitHub 
curl -LsSf https://github.com/reapr-corp/reapr/releases/latest/download/rpr-installer.sh | sh
rpr run --diff origin/main

rpr 0.2.0 for Linux (x86_64, aarch64). Needs git, Node.js 20.10 or later, and StrykerJS with a config file. macOS and Windows are planned.

/ Why

Coverage measures execution, not verification.

Teams ship a lot of AI-generated code, and agents write tests that pass. The mutation score tells you whether those tests protect behavior. Time keeps it out of pull requests: a full run takes 40 to 90 minutes. Reapr scopes it to the diff.

Line coverage asks
Did a test run this line?yes, 100%
The mutation score asks
If this line changed, would a test fail?no, it survived

/ How it works

Your engine, your config, only your diff.

  1. Read the diff

    git diff <base>...HEAD gives the changed line ranges.

    src/a.ts:8-12
    src/b.ts:5-6
    docs/usage.md:3-4

  2. Run Stryker on it

    Your config's mutate globs pick the files. A wrapper imports your config and sets only mutate and a json reporter.

    src/a.ts:8-12
    src/b.ts:5-6
    docs/usage.md:3-4

  3. Score the diff

    Reapr keeps the mutants inside the changed ranges, computes the score and writes the run record.

    score 80.00%
    2 survived

File names are an example. Your test runner, thresholds, timeouts, checkers and plugins stay as you wrote them. What Reapr changes in your config.

/ Output

A summary for people. JSON for agents.

Each survivor has the file, line, column, mutator and replacement: enough for an agent to write the missing test and run Reapr again. Reapr reports. It does not write tests.

Samples from the README. Exit codes: 0 passed, 1 below --min-score or the engine's threshold failed, 2 error.

/ GitHub Action

Run it on every pull request.

reapr-corp/run@v1 writes a job summary with the score, counts, survivors and warnings, and exits with Reapr's exit code. Linux runners. No token needed.

/ Principles

What Reapr does and does not do.

We invent nothing
Reapr runs your engine config as written and adds only the diff scope and a JSON reporter. It forces no flags. When a setting can miscount results, it warns and changes nothing.
Agents are first-class users
--json prints one document with every surviving mutant. An MCP server is planned.
Every run leaves raw data
Run facts, both reports and the wrapper config go to .git/reapr/runs/<run_id>/ on your machine. Reapr never uploads or deletes them.
Anonymous, opt-out telemetry
One event per run: outcome, counts, durations, bucketed diff size. Never code, paths or names. DO_NOT_TRACK=1 turns it off. Every property.
