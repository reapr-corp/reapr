# Code of conduct

Reapr adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone in the project's spaces: issues, pull requests, discussions and
any other channel the project uses.

To report unacceptable behavior, open a private security advisory at
<https://github.com/reapr-corp/reapr/security/advisories/new> or contact the maintainers via GitHub. Reports are
handled in confidence by the maintainers, who will act as the Covenant's enforcement guidelines describe.
